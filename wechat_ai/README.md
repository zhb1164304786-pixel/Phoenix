# 微信 AI 自动回复

朋友给你发微信时，让 Claude 用你的微信号帮你回复。

## 先看风险

- **可能被封号。** 微信官方不允许用程序操控个人微信。这个程序模拟鼠标和键盘去操作微信电脑版，被发现的话，轻则功能受限，重则封号。建议先用小号试。
- **用的是第三方工具。** 控制微信的部分用的是 [wxauto4](https://pypi.org/project/wxauto4/)，这是别人写的、不公开源代码的库，不是腾讯官方的东西。
- **朋友的消息会发给 Anthropic。** 每次回复，最近 20 条聊天记录会发给 Claude 去理解上下文。最好提前跟白名单里的朋友打个招呼。
- **微信一更新，程序可能就用不了。** wxauto4 的说明写的是适用微信 4.1.8 版。

## 你需要准备

1. 一台 **Windows 电脑**，装好并登录**微信电脑版**。
2. **Python 3.12**：从 python.org 下载安装，安装时一定要勾选 "Add Python to PATH"。
3. 一个 **Claude API 密钥**：在 console.anthropic.com 注册，充值后创建密钥（以 `sk-ant-` 开头）。按用量收费。

## 安装

1. 把这个 `wechat_ai` 文件夹下载到电脑上。
2. 打开这个文件夹，在地址栏输入 `cmd` 后按回车，会弹出一个黑色的命令窗口。
3. 在窗口里输入下面这行，按回车，等它装完：

   ```
   pip install -r requirements.txt
   ```

4. 设置密钥（把引号里换成你自己的密钥）：

   ```
   setx ANTHROPIC_API_KEY "sk-ant-你的密钥"
   ```

   设置完**关掉命令窗口，再重新打开一个**，新设置才会生效。

## 第一步：先试试 AI 怎么回

不连微信，你自己扮演朋友跟 AI 聊几句：

```
python bot.py --test
```

觉得语气不对，就去改 `config.py` 里的 `PERSONA`，用大白话告诉它该怎么回。

## 第二步：设置要自动回复谁

用记事本打开 `config.py`：

- `OWNER_NAME`：改成你的名字。
- `WHITELIST`：填上要自动回复的人。名字要和微信里显示的**完全一样**，有备注就填备注。只有名单里的人会收到自动回复，群聊不会。

## 第三步：开始自动回复

确认微信电脑版已经登录，然后运行：

```
python bot.py
```

运行期间：

- **不要动微信窗口**，程序会自己点它。
- 电脑不能睡眠或锁屏。
- 想停下来就按 `Ctrl + C`。

## 它是怎么工作的

1. 每隔 3 秒看一眼微信左侧的会话列表，找白名单里有新消息的人。
2. 打开那个聊天，读最近的聊天记录。
3. 如果最后一条是对方发的，就把记录交给 Claude，拿到回复后发出去，前面带上 `[AI代回]` 标记。
4. 如果最后一条是你发的（比如你已经亲自回了），就不打扰。

保护措施：

- 每人每小时最多自动回复 20 条，防止和别的机器人聊个没完。
- AI 被要求不替你答应借钱、约时间这类事，也不乱编你的私事。
- 对方问它是不是 AI，它会如实说是。

## 花多少钱

默认用 Claude Opus 5.5。每条回复大概几分钱人民币，具体看聊天记录有多长。想省钱可以在 `config.py` 里把 `MODEL` 改成 `"claude-haiku-5-5"`，会便宜很多。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `config.py` | 所有设置都在这里，平时只改它 |
| `bot.py` | 主程序：看微信、读消息、发回复 |
| `ai_reply.py` | 把聊天记录交给 Claude，拿回一句回复 |
| `requirements.txt` | 需要安装的库 |
